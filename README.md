# Online Learning Platform

Ιδιωτικό project για την ανάπτυξη ολοκληρωμένης πλατφόρμας online μαθημάτων.

## Στόχος
Ο καθηγητής και ο μαθητής να πραγματοποιούν το μάθημα μέσα στην ίδια την πλατφόρμα, με εργαλεία διδασκαλίας και διαχείρισης.

## Τρέχον prototype
- Dashboard καθηγητή
- Πρόγραμμα μαθημάτων
- Virtual classroom
- Ψηφιακός πίνακας
- Θέσεις video καθηγητή / μαθητή
- Chat
- Screen sharing hook
- Μαθητές
- Εργασίες
- Responsive mobile interface

## Επόμενα στάδια
1. Authentication και ρόλοι καθηγητή / μαθητή
2. Database για χρήστες, μαθήματα, κρατήσεις και εργασίες
3. Πραγματικό WebRTC video/audio classroom
4. Shared realtime whiteboard
5. PDF upload και annotation
6. File sharing και homework workflow
7. Booking / calendar
8. Notifications
9. Production deployment και domain
